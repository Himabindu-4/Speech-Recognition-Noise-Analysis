# Reproducibility Checklist

Before submitting:

- [ ] Python version recorded
- [ ] PyTorch version recorded
- [ ] Whisper version recorded
- [ ] CPU/GPU recorded
- [ ] LibriSpeech split recorded
- [ ] MUSAN category recorded
- [ ] Number of evaluated samples recorded
- [ ] Total evaluated duration calculated
- [ ] Number of unique speakers calculated
- [ ] SNR values recorded
- [ ] WER calculated
- [ ] CER calculated
- [ ] Mean latency calculated
- [ ] RTF calculated
- [ ] WER vs SNR plot generated
- [ ] CER vs SNR plot generated
- [ ] System-metric plot generated
- [ ] Spectrogram generated
- [ ] 3–5 errors manually listened to
- [ ] Error causes supported by audio evidence
- [ ] No fabricated values in the report
- [ ] Figures numbered and captioned
- [ ] GitHub repository is viewable
- [ ] Dataset files are NOT committed to GitHub
- [ ] Final PDF filename follows the required RollNo_Name_CaseStudy.pdf format
